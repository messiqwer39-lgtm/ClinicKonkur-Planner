## ۵. نحوه بیلد و خروجی APK برای بارگذاری در بازار و مایکت

این پروژه دارای `manifest.webmanifest` و Service Worker آفلاین است و با استفاده از روش‌های استاندارد زیر در کمتر از چند دقیقه به APK تبدیل می‌شود:

### روش اول: با استفاده از ابزار Bubblewrap (روش رسمی Google TWA):
```bash
npm install -g @bubblewrap/cli
bubblewrap init --manifest=https://your-domain.com/manifest.webmanifest
bubblewrap build
```

### روش دوم: با استفاده از Capacitor:
```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "Clinic Konkur Planner" "com.clinickonkur.planner"
npm run build
npx cap add android
npx cap sync
npx cap open android
```
سپس در Android Studio از منوی `Build > Generate Signed Bundle / APK` خروجی APK را دریافت کنید.

### روش سوم: بارگذاری مستقیم در مایکت و بازار (PWA Package):
کافه بازار و مایکت از بارگذاری پکیج PWA یا وب‌اپلیکیشن به صورت مستقیم نیز پشتیبانی می‌کنند.

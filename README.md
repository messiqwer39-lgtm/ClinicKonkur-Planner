# کلینیک پلن | Clinic Plan — برنامه‌ریز تخصصی کنکور

اپلیکیشن برنامه‌ریزی کنکور با سیستم ۸ پارت روزانه، گزارش‌کار تحلیلی، شمارش معکوس کنکور ۱۴۰۶، برنامه چاپی کامل هر سه رشته و مشاوره کلینیک کنکور.

## نصب نسخه اندروید (APK)

آخرین نسخه امضاشده را از صفحه [Releases](https://github.com/messiqwer39-lgtm/ClinicKonkur-Planner/releases/latest) دانلود کنید.

نصب مستقیم فایل APK خارج از گوگل‌پلی است، بنابراین ممکن است Google Play Protect یک هشدار عمومی «اپ بررسی نشده» نشان دهد. این هشدار درباره هر APK نصب‌شده خارج از پلی استور نمایش داده می‌شود و به معنی ویروس بودن نیست:

1. روی هشدار Play Protect، **جزئیات بیشتر (More details)** → **نصب به هر حال (Install anyway)** را بزنید.
2. برای حذف دائمی هشدار، می‌توانید از [فرم بررسی اشتباه Play Protect](https://support.google.com/googleplay/android-developer/contact/protect-appeals) درخواست بازبینی دهید.

### چرا این APK امن است؟

- امضای Release با کلید اختصاصی + طرح‌های امضای v1/v2/v3
- **بدون هیچ دسترسی (Permission)** — حتی اینترنت؛ اپ ۱۰۰٪ آفلاین است
- بدون ترافیک رمزنشده، بدون کد ریموت — همه فایل‌ها داخل خود APK
- انتشار فقط از طریق GitHub Releases (دامنه معتبر و شناخته‌شده)
- هدف‌گذاری targetSdk 34 مطابق سیاست‌های روز گوگل

## امکانات

- صفحه خوش‌آمد ساده با ورود خودکار به پنل و بنر کلینیک کنکور
- ویجت پیشرفت روزانه با حلقه‌های انیمیشنی (درصد پارت‌ها، تست‌ها، هفته)
- برنامه‌ریزی ۸ پارت روزانه + شمارنده تست + تایمر پومودورو
- شمارش معکوس انیمیشنی تا ۱۰ تیر ۱۴۰۶
- چاپ برنامه کامل: جدول هفتگی، گزارش کار و چک‌لیست همه دروس **تجربی، ریاضی و انسانی**
- بنرهای تبلیغاتی کلینیک کنکور در صفحات
- ذخیره‌سازی محلی (localStorage) — داده‌ها فقط روی دستگاه خودتان
- نصب به‌صورت PWA (وب) یا APK آفلاین

## بیلد و توسعه

```bash
bun install
bun run dev      # اجرای محیط توسعه
bun run build    # خروجی وب در dist/
bun run lint     # بررسی تایپ‌اسکریپت
```

برای ساخت APK اندروید به [android/README.md](android/README.md) مراجعه کنید.
